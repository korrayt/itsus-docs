# itsus-docs

## Amaç

IT'S US Creative AI Lab için iş fikirleri, ürün notları, marka dokümanları ve teknik kayıtlar.

## Durum

Private / başlangıç

## Klasör Yapısı

- `brand/` - Marka, dil ve kimlik notları.
- `business/` - İş modeli ve operasyon notları.
- `product/` - Ürün planları ve keşif notları.
- `legal/` - Hukuki ve sözleşmesel notlar.
- `technical/` - Teknik kararlar ve uygulama kayıtları.
- `docs/` - Mimari, yol haritası ve karar notları.

## Çalıştırma

```bash
bash scripts/setup.sh
bash scripts/dev.sh
```

## Güvenlik Notu

API key, token, müşteri dosyası ve gizli bilgi commitlenmemeli.
