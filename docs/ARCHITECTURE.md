# Architecture

## Overview

This repo should keep brand, business, product, legal, and technical notes clearly separated.

## Boundaries

- `brand/` owns identity and messaging notes.
- `business/` owns business-side thinking.
- `product/` owns product discovery and planning.
- `legal/` owns legal references.
- `technical/` owns technical decisions and notes.

## Notes

Keep the documentation set easy to audit and easy to archive.
